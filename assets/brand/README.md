# mailcleaner brand

Everything here is generated by [`packaging/brand/build.py`](../../packaging/brand/build.py)
from one definition of the mark and the wordmark. Change the script, not the files.

## The mark

An envelope whose flap is a tick that leaves it through the open top-right
corner: mail, sorted. One line weight on a rounded terracotta square.

| File | Use |
|---|---|
| `mark.svg` | The mark, 48 px and up |
| `mark-small.svg` | 16-32 px (favicons, tabs): a heavier line so it does not thin out |
| `mark-dark.svg` | On a dark ground where the terracotta square would be too loud |
| `glyph.svg` | The line art alone, in `currentColor`, for single-colour use |
| `app-icon.svg` | The mark inside the macOS icon grid (clear margin around it) |
| `icon-{32,128,256,512,1024}.png` | Rasters of the mark |
| `mailcleaner.ico` | Windows (16-256 px), used for the `.exe` |
| `mailcleaner.icns` | macOS |

## The name

Always **mailcleaner**: one word, lowercase, in Geist SemiBold tracked -0.02em.
The command is `mclean`; the name is never written that way in prose or UI.

| File | Use |
|---|---|
| `lockup.svg` / `lockup-dark.svg` | Mark and name together: README, website, docs |
| `wordmark.svg` / `wordmark-dark.svg` | The name alone, when the mark is already nearby |
| `social.svg` / `social.png` | 1280x640 repository preview (Settings -> Social preview on GitHub) |

All text in these files is outlined, so they look the same without the font
installed. In the app, the same setting is live text in Geist.

|---|---|---|
| Terracotta (the brand) | `#9e4421` | `--accent`, oklch(0.50 0.13 40) |
| Ink | `#241e1a` | `--ink` |
| Paper | `#f7f4ee` | `--bg` |
| Night | `#1f1915` | `--dark` |
| Protected green | `#2b7440` | `--green`. Means "protected" and nothing else; never part of the logo |

## Rules

- Clear space around the mark: at least a quarter of its width.
- Do not recolour the tick, add a gradient or shadow, rotate it, or put the
  mark on terracotta.
- Do not set the name in another font, in capitals, or as two words.

Fonts: [Geist](https://github.com/vercel/geist-font), SIL Open Font License 1.1.
Only outlines derived from it are distributed here.
